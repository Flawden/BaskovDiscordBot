# Queue Experience

Начиная с `v0.5.0`, музыкальная очередь хранит не только `AudioTrack`, но и данные пользователя, который заказал трек.
Это позволяет показывать requester, прогноз старта и управлять ожидающими треками без остановки текущей песни.

В `v0.10.0` очередь получила постраничную навигацию по 10 позиций, глобальные номера треков и отдельный ETA старта для каждой строки.

## Slash-команды

| Команда | Назначение |
|---|---|
| `/previous` | Возвращает последний завершённый или пропущенный трек; текущий ставит первым в очередь |
| `/queue [page]` | Текущий трек, выбранная страница из 10 позиций, requester, ETA каждой строки, громкость и repeat mode |
| `/remove position` | Удаляет ожидающий трек по номеру из `/queue` |
| `/move from to` | Перемещает ожидающий трек между позициями |
| `/shuffle` | Перемешивает только ожидающие треки |
| `/clear` | Очищает ожидающие треки, но не прерывает текущий |
| `/volume level` | Устанавливает громкость от 0 до настроенного максимума |
| `/repeat mode` | `off`, `track` или `queue` |

Все изменяющие команды проходят общую `MusicControlPolicy`: обычный участник должен находиться в том же voice channel, что и бот. Владелец сервера и участник с `Manage Server` сохраняют административный override.

## Requester и ETA

Для каждого добавленного трека сохраняются:

- Discord user ID;
- отображаемое имя на момент заказа;
- время добавления;
- исходный `AudioTrack`.

Ответ `/play` показывает requester, позицию и приблизительное время до старта. `/queue` повторяет расчёт отдельно для каждой видимой позиции. ETA рассчитывается из остатка текущего трека и длительности уже ожидающих треков. Это прогноз, а не гарантия: skip, seek, remove, shuffle и сетевые ошибки меняют фактическое время.

## Страницы и кнопки

- `/queue` открывает первую страницу;
- `/queue page:3` сразу показывает третью страницу;
- кнопки `◀ Назад` и `Вперёд ▶` редактируют то же сообщение и не создают поток новых ответов;
- номер позиции остаётся глобальным для всей очереди, поэтому его можно напрямую использовать в `/remove position` и `/move from to`;
- запрос страницы за пределами очереди безопасно переводится на последнюю доступную страницу;
- навигация read-only и не требует права управления активным voice-сеансом.

`/now` и блок текущего трека в `/queue` показывают визуальную шкалу прогресса, позицию и оставшееся время.

## Повтор

- `off` — обычное воспроизведение;
- `track` — после естественного завершения повторяется текущий трек;
- `queue` — завершившийся трек добавляется в конец очереди.

Кнопка `Повтор` циклически переключает `off → track → queue → off`.
Ручной skip не считается естественным завершением и не заставляет пропущенный трек повторяться. При этом трек попадает в bounded history и доступен через `/previous`.

## Громкость

Новая сессия получает `DISCORD_BOT_MUSIC_DEFAULT_VOLUME`. `/volume` ограничен значением `DISCORD_BOT_MUSIC_MAX_VOLUME`.

```text
DISCORD_BOT_MUSIC_DEFAULT_VOLUME=100
DISCORD_BOT_MUSIC_MAX_VOLUME=150
```

Границы:

- default volume: от 0 до max volume;
- max volume: от 1 до 500.

Громкость и repeat mode по умолчанию сохраняются между перезапусками через guild-настройки.
