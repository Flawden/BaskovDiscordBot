# 🎤 Baskov Discord Bot
## Автор: Flawden

> Музыкальный Discord-бот, построенный на базе Spring Boot. Поддерживает масштабирование, легко расширяется и прост в сопровождении.

---

## 🚀 Возможности

- 📻 Воспроизведение музыки, пауза, пропуск трека
- 🔧 Расширяемая система команд (на событиях Spring)
- 💡 Чистая архитектура и читаемый код
- 🧩 Удобен для обучения, хакерства и моддинга

## 🛠️ Технологии


- ☕ **Java 17**
- 🚀 **Spring Boot**
- 📦 **Maven**
- 🤖 **JDA** — работа с Discord API
- 🎵 **LavaPlayer** — воспроизведение музыки
- 🧬 **Lombok** — сокращение шаблонного кода
- 📄 **SLF4J** — логгирование
